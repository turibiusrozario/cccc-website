# Website: CCCC

2026-10-26

This is the input file to construct the preliminary website for the
Massachusetts Cross Campus Climate Coalition. Domain does not currently exist to
host, but will soon.

## RQ-## Requirements

1. Information on what we are is provided.
2. Form to join/contact us.
3. Space to list out upcoming events.
4. Space to list out ongoing/upcoming projects.
5. Space to list upcoming action items/opportunities (e.g. petitions,
   fellowships, etc.).
6. Space that shows past events, projects, and action items.
7. Content can be edited by human with low coding experience.
8. Static website hosted on Github Pages.
9. Space to link to other resources.
10. Mobile-friendly.
11. Accessible (large print, light/dark auto respecting, large spacing).
12. Follows research-backed or well-documented guidelines on UI experience.
13. Simple logo visible from afar.
14. Refreshes with new content (i.e., client side prompts to update if, for
    example, event gets added)
15. ASD friendly (in terms of appearance)

## ID-## Ideas

1. Google sheet as source of event/project/action content, with app scripts
   controlling whether it gets displayed (e.g. start and end date provided on
   the spreadsheet, and when the script detects that it has past, an event goes from
   upcoming to past.). For RQ-07. 
2. Logo has three academic hat icons and one institution icon connected in a
   ring. 3 colors only. Can be distinguished if ever printed in black and white.
   Distinguishable at 16 px. 
3. RQ-03, RQ-04, and RQ-05 are on front page, but capped to 3 each with most
   upcoming taking precedence.
4. Clicking on a event/project/action expands to show its description or sends
   to link if description not provided (but link is). State something like
   'Click to show more' for RQ-15. Replace with the 'opens to new tab' icon for
   the link case. 
5. Separate page that has RQ-06 past items.
6. Separate page for other resources (links to other websites, documents, etc.)
7. RQ-01 and RQ-02 on front page. 
8. For RQ-15, check existing research/documentation on what is friendly (e.g. no
   flashes, no overstimulations, wording that is true).
